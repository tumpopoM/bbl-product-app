# React Native Product Favorites App

A React Native + TypeScript application that displays products from a public API and allows users to manage favorite products.

## Features

- Fetch products from API
- Product list screen
- Product detail screen
- Add / Remove favorites
- Favorites screen
- Pull to refresh
- Favorites persistence with AsyncStorage

## Tech Stack

- React Native
- TypeScript
- React Navigation
- Context API
- AsyncStorage

## Installation

```bash
npm install
```

## Run Android

```bash
npx react-native run-android
```
